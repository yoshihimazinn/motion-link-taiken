# Motion-Link 体験版

座ったまま運動をして、写真の曇りをふいてきれいにする試作です。使ってみた感想をいただくために公開しています。

## はじめかた

### ブラウザで遊ぶ（いちばんかんたん）

https://yoshihimazinn.github.io/motion-link-taiken/ を Chrome か Edge で開き、「ブラウザで はじめる」を押します。「カメラを使いますか」と聞かれたら「許可」を押してください。

### Windows の PC に入れて使う

1. [`download/Motion-Link-taiken.zip`](download/Motion-Link-taiken.zip) を開き、ダウンロードのボタンを押します（約47MB）。
2. zip を右クリックして「すべて展開」を選びます。
3. 展開したフォルダの「Motion-Linkをはじめる」をダブルクリックします（くわしくは中の「はじめにお読みください」）。

### 手元のフォルダから開く（Mac など。Chrome か Edge）

1. このリポジトリを手元に取ってきます（`git clone`、または「Code」→「Download ZIP」）。
2. 取ってきたフォルダで、小さなサーバーを動かします。カメラを使うので、`index.html` をダブルクリックで開いても動きません。

   ```
   python3 -m http.server 8000
   ```

3. http://localhost:8000/ を開き、「ブラウザで はじめる」を押します。「カメラを使いますか」と聞かれたら「許可」を押してください。

カメラのついた PC で、座った体全体（頭から足もとまで）が映るように、少し離れて座ってください。

## 感想の送りかた

1. 最初の画面の「感想を送る」を押します。
2. 「よかった」「わかりにくい」「うまく動かない」「こうしてほしい」から1つ選び、ひとこと書けます。
3. 「ファイルに保存する」を押すと、「ダウンロード」に感想のファイルができます。
4. そのファイルを、この体験版を教えてくれた人に送ってください。このリポジトリの Issue に書いていただいてもかまいません。

## 安心して使っていただくために

- カメラの映像は、保存も送信もしません。体の動きを数えるためだけに、お使いのブラウザの中で使います。
- 運動の記録は、お使いのブラウザの中にだけ残ります。
- 設定の画面はありません（数え方は変えられません）。

## 中身

- `index.html`：はじめのページ
- `app/`：体験版の画面（ブラウザで動く）。体の動きを読む仕組み（MediaPipe）のファイルも入っています
- `download/Motion-Link-taiken.zip`：Windows の PC に入れて使う体験版
